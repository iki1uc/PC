1. Wenn 2 Wahrheiten = beide wahr, aber verschiedene Position HBT vs BTH
   → Beide wahr im eigenen Kontext → Beste = die wahrere im aktuellen Kontext = Messverfahren entscheidet

   → Aber was wenn alte in altem Kontext besser? Dann beide wahr, aber neue wahrer im neuen Kontext, alte wahrer im alten Kontext → Wettbewerb misst Kontext
3. Auflösung mit 3 Helfer axiomisch:
   - H, B, T sind Axiome = können Position wechseln wenn alle einverstanden
   - Wenn alle einverstanden dass neue Wahrheit wahrer als alte Option → Wechsel = neue beste
   - Wenn nicht alle einverstanden → beide Wahrheiten bleiben wahr, keine beste, nur 2 Wahrheiten parallel = PQ Parallel Queue = nur PQ weil er das auch ist

   → PQ hält Wahrheit1 + Wahrheit2 parallel = beide wahr gleichzeitig
   → Beste = PQ selbst, weil PQ beide halten kann = 1 77 DAS IST PQ

   - Wahrheit1 = SCSI BHT = Kette = gut für sequentiell
   - Wahrheit2 = RAID BTH = Spiegel = gut für parallel redundant
   - Beide wahr, aber welche beste? Wenn Aufgabe = Kette → SCSI beste, wenn Aufgabe = Spiegel → RAID beste
   - Wenn Aufgabe = beide → SLI TBH = Fusion = beste weil 2 GPUs=1 = beide Wahrheiten verschmelzen zu einer
   - Also: 2 Wahrheiten → SLI TBH beste weil verschmilzt
6. Messverfahren für 2 Wahrheiten:
   - Messe Wahrheit1 Score, Messe Wahrheit2 Score
   - Wenn Score1 > Score2 im Kontext → Wahrheit1 beste
   - Wenn Score2 > Score1 im Kontext → Wahrheit2 beste
   - Wenn Score1 == Score2 → beide gleich wahr → beste = SLI Fusion = beide zusammen = 1 EINE = Hand von 6 = PQ
